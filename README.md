## 🔐 Security Note

Do **not** store database passwords, API keys, JWT secrets, or other sensitive credentials directly in source code.

For local development, use environment variables or a configuration file that is excluded from Git using `.gitignore`.

Example:

```env
DB_USERNAME=root
DB_PASSWORD=your_password
```
